# Excel VBA Reconciliation Tool

Compare two Excel sheets by summing numeric columns grouped by an ID field. Results land in match/error sheets with optional transforms and multi-workflow configs.

## Quick start

1. Open [`ExcelVBA/`](ExcelVBA/) and follow [SETUP_INSTRUCTIONS.md](ExcelVBA/SETUP_INSTRUCTIONS.md)
2. Import [`ReconModule.vba`](ExcelVBA/ReconModule.vba) and [`ReconForm.vba`](ExcelVBA/ReconForm.vba), or use the sample workbook [`ExcelVBA/ReconMacro.xlsm`](ExcelVBA/ReconMacro.xlsm)
3. Configure via the sample CSVs / docs in `ExcelVBA/`
